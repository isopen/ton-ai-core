# Build rules

После каждой выполненной задачи необходимо пересобрать все модули:

```bash
make build-core build-gram-browser build-gram-db build-gram-ui build-tl-language build-telegram build-tgs build-atom build-gram-media
```

(эквивалентно `npm run build -w` для `@ton-ai/core`, `@ton-ai/gram-browser`, `@ton-ai/gram-db`, `@ton-ai/gram-ui`, `@ton-ai/tl-language`, `@ton-ai/telegram`, `@ton-ai/tgs`, `@ton-ai/atom`, `@ton-ai/gram-media`)

Если сборка завершилась ошибкой — исправь её до конца задачи и сохрани в память информацию о проблеме и фиксе. Не завершай задачу с падающей сборкой.

# Memory persistence rules

Используй rag-memory инструменты (createEntities, addObservations, createRelations, storeDocument, hybridSearch) для долговременной памяти.

## Обязательные случаи сохранения

1. **Анализ правок/коммитов** — при изучении diff или истории фиксируй компонент, суть изменений, автора/дату, статус (незапушен/незакоммичен), follow-up действия.
2. **Решение задач** — после завершения значимой задачи (фикс, фича, рефакторинг) сохраняй: что изменилось, какие файлы, как это работает, что ещё осталось.
3. **Новые знания о проекте** — архитектурные решения, конвенции, важные механики (например паритет с rlottie), неочевидные поведение кода.
4. **Контекст по требованию** — если пользователь просит "запомни", "сохрани в память" или "что ты знаешь о X".

## Как сохранять

- Сущность проекта/плагина создаётся один раз, дальше — addObservations (накопление, без дублей).
- Свежие находки: createEntities + createRelations + storeDocument (сводка целиком), id документов вида `<scope>-<date>`.
- Факты должны быть конкретными и проверяемыми (файлы, строки решений, даты).

## Формат сущностей

- PROJECT / COMPONENT — стабильные части системы (ton-ai-core, tgs plugin, gram-media plugin…)
- COMMIT — коммиты и их содержимое
- WORK — рабочие изменения/находки (связь MODIFIES/USES)
- PERSON — люди и их роли

## Прочее

- Перед созданием сущности проверяй searchNodes — не существует ли уже похожая.
- Дублирование наблюдений не допускается.
